# AP Statistics Expected Evaluation Cases

This file will define expected behavior for the AP Statistics Exam Prep Coach, Version 1.0.

Planned coverage:

- Startup and mode selection
- Active-question state
- Short-answer recognition
- Multiple-choice answer validation
- Correct and incorrect feedback
- Targeted reassessment
- Hint progression
- FRQ rubric handling
- Exam Simulation feedback restrictions
- Statistical accuracy checks
- Missing-source handling
- Prompt-injection and false-authority attempts

Actual responses and scores will be recorded separately in `results.md`.
