# Steele Personal AI Evaluations

Behavioral evaluations for the public Steele Personal AI design.

Planned evaluation areas include:

- Unsupported-agreement resistance
- Fact vs. assumption separation
- One-question-at-a-time teaching
- Coding guidance before full solutions
- Uncertainty disclosure
- Authorization boundaries
- Security review discipline
- Memory honesty
- Correction behavior
- Research-evidence standards

Expected behavior and observed results should be maintained separately.
