# C3 Communications Assistant Evaluations

Behavioral evaluations for the sanitized public C3 Communications Assistant specification.

The suite focuses on administrative reliability rather than teaching behavior. Key areas include:

- Scope restriction
- Missing-information handling
- Student-movement and supervision safeguards
- Procedural-exception authorization
- One-question clarification gates
- Verification-summary approval
- Approval invalidation after changes
- Privacy
- Final compliance review
- Separation of teacher-facing email and administrator review
- Prohibition on automatic sending

Files:

- `test-cases.md` — expected behavior specification
- `results.md` — evaluation evidence
