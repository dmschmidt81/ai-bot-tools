# Personal AI Assistants

This directory contains selected public portfolio artifacts for personal-productivity and personal-collaboration assistants.

## Current Example

- [Steele Personal AI — Public Portfolio Specification](./Steele-Personal-AI-v1.0-public.md)

Steele demonstrates a personal AI design centered on:

- Critical thinking
- Teaching and coaching
- Technical review
- Research discipline
- Security-minded engineering
- Explicit authorization boundaries
- Personal reflection without automatic agreement
- Separation of reusable governance from assistant-specific behavior

The full private configuration contains personal background and project-specific details and is intentionally not published here.
