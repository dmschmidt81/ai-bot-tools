# Security and Public Disclosure Policy

This is a public portfolio repository, not a production AI service.

## Public-Repository Rules

Do not commit:

- Passwords, API keys, tokens, recovery codes, certificates, or private keys
- Private environment files or credential stores
- Student, employee, applicant, patient, or other sensitive personal records
- Live internal operational links that are not intentionally public
- Private production bot configurations when a sanitized portfolio snapshot is sufficient
- Proprietary answer keys, restricted assessment materials, or confidential organizational procedures
- Logs or screenshots containing secrets or private data

## Publication Boundary

Before publishing an AI artifact:

1. Identify the public portfolio purpose.
2. Remove personal or organization-specific sensitive information.
3. Replace live operational resources with descriptions or placeholders where possible.
4. Publish representative design patterns rather than unnecessary production detail.
5. Verify that evaluation claims distinguish dry runs, simulations, and deployed runtime evidence.
6. Check that third-party material is not being republished beyond what is appropriate.
7. Confirm the intended license or reuse terms.

## Prompt and Agent Security

Public prompt text is documentation, not an enforceable security boundary. Deployed systems should use technical controls for permissions, secrets, network access, data handling, and external actions.

## Reporting an Issue

For non-sensitive documentation issues, a normal GitHub issue may be appropriate.

Do not post secrets, personal data, or sensitive exploit details in a public issue. Use a private contact method available through the repository owner's GitHub or professional profile for sensitive reports.

## Production Claims

Nothing in this public repository should be interpreted as a claim that a deployed system is vulnerability-free, certified, penetration-tested, or production-approved unless a specific artifact provides the supporting evidence.
