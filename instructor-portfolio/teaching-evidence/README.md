# Teaching Evidence

The GitHub artifacts in this repository demonstrate curriculum design, assessment design, AI-system thinking, and responsible-AI workflows.

Recorded teaching demonstrates a different competency: **actual delivery**.

## Evidence Sources

Selected public videos can include:

- LinkedIn instructional videos
- MathDragon YouTube videos
- Other public teaching demonstrations

## What the Videos Can Prove

Strong examples can demonstrate:

- Explaining technical concepts clearly
- Breaking complex ideas into manageable steps
- Using examples and analogies
- Teaching programming and web-development concepts
- Teaching AI literacy
- Adjusting explanations for mixed-skill audiences
- On-camera communication
- Concise instructional delivery

## Selection Standard

Use a small number of strong examples rather than an unfiltered archive.

For each selected video, document:

| Field | What to record |
|---|---|
| Title | Public video title |
| Topic | What is being taught |
| Audience | Intended learner |
| Length | Approximate runtime |
| Teaching skill | What the video demonstrates |
| Link | Public URL |

## Recommended Evidence Mix

A balanced set might include:

1. One programming concept
2. One web-development concept
3. One AI-literacy or responsible-AI concept
4. One short concept explanation using an analogy
5. The 15-minute AI instructor demonstration from this portfolio

## Portfolio Principle

**The repository proves the instructional system. The videos prove the instructor can deliver it.**
