# Practical Generative AI: From Prompt to Reliable Workflow

**Format:** Instructor-led workshop  
**Length:** 75–90 minutes  
**Audience:** Educators, administrators, knowledge workers, and professionals beginning to use generative AI  
**Level:** Introductory to intermediate  
**Delivery:** In person or virtual

## Course Purpose

This workshop teaches learners to use generative AI as a reasoning and workflow tool rather than treating it as an automatic answer machine.

The central idea:

> A useful AI response is not the end of the process. It is the beginning of evaluation.

Learners practice:

**Prompt → Evaluate → Verify → Improve → Govern → Apply**

## Learning Objectives

By the end of the workshop, learners will be able to:

1. Explain at a practical level why confident AI output can still be wrong.
2. Turn a vague request into a structured AI task using context, constraints, sources, and output requirements.
3. Separate generated claims into facts, assumptions, interpretations, recommendations, and unknowns.
4. Verify AI output using appropriate sources, calculations, tests, or governing documents.
5. Identify privacy, authorization, hallucination, and prompt-injection risks.
6. Decide when a human approval gate is necessary.
7. Convert a useful prompt into a repeatable human-in-the-loop workflow.

## Workshop Sequence

| Segment | Approx. time | Focus |
|---|---:|---|
| Opening and pre-assessment | 10 min | Existing beliefs and AI mental model |
| Module 1 | 15 min | What generative AI is doing |
| Module 2 | 15 min | Better task and prompt design |
| Module 3 | 20 min | Verification and failure detection |
| Module 4 | 15 min | Workflow design and responsible AI |
| Post-assessment and reflection | 10–15 min | Transfer and next steps |

## Instructor Portfolio Note

This course is designed to demonstrate practical AI instruction, adult-learning design, responsible-AI facilitation, and assessment—not simply prompt writing.
