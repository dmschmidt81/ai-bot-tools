# Practical Generative AI — Quick Reference

## Build Better Tasks

**Task → Context → Source → Constraints → Output → Verification**

## Evaluate the Response

Ask:

- What is supported?
- What was assumed?
- What is missing?
- What matters if wrong?

## Verify by Output Type

- **Fact:** authoritative source
- **Current claim:** current dated source
- **Math:** recalculate
- **Code:** test
- **Policy:** governing document
- **Summary:** compare with source

## Risk Check

- Privacy
- Authorization
- Hallucination
- Prompt injection

## Human-in-the-Loop Pattern

**Input → AI → Verification → Risk Check → Human Approval → Action**

## Quality Sequence

**VERIFY → ASSESS → CORRECT → REVERIFY → DELIVER**

## Core Rule

A confident answer is not evidence.
