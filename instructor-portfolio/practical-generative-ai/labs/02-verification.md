# Lab 2 — Verification

## Goal

Practice checking AI output instead of judging it by confidence or writing quality.

## Scenario

An AI response contains:

- a current factual claim,
- a numerical calculation,
- a recommendation,
- and a statement about organizational policy.

## Task

For each statement, classify it as:

- Fact
- Assumption
- Interpretation
- Unknown
- Recommendation

Then choose the appropriate verification method.

## Reflection

Which statement would create the greatest risk if it were wrong, and why?

## Success Criteria

Verification method matches the type and consequence of the claim.
